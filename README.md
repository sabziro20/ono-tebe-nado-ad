# Одностраничный лендинг «Оно тебе надо»

Учебный проект одностраничного сайта аукциона необычных вещей и редких лотов («Оно тебе надо»), созданный в рамках практического обучения веб-разработке.

---

## 🛠 Технологии и стек
* **HTML5**: семантическая разметка (`header`, `main`, `section`, `footer`, `nav`, `address`), правильная структура вложенности.
* **CSS3**: гибкая верстка на **Flexbox**, кастомное подключение шрифтов через `@font-face` (формат `woff2`), управление слоями через `z-index` и абсолютное позиционирование.
* **Методология БЭМ (Block, Element, Modifier)**: чистое и понятное именование классов (`kebab-case`).
* **Пиксель-перфект**: точное соответствие макету в Figma, кроссбраузерность.
